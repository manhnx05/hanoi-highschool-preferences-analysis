========================================
  HUONG DAN GIT - Commit va Push
========================================

📌 CAC LENH GIT CO BAN:
------------------------

1. KIEM TRA TRANG THAI:
   git status

2. THEM FILE VAO STAGING:
   git add .                    # Them tat ca file
   git add <file_name>          # Them file cu the

3. COMMIT VOI MESSAGE:
   git commit -m "message"

4. PUSH LEN GITHUB:
   git push origin main

5. PULL TU GITHUB:
   git pull origin main


📝 CAC LOAI COMMIT MESSAGE:
----------------------------

feat:     Them tinh nang moi
fix:      Sua loi
docs:     Cap nhat tai lieu
style:    Thay doi giao dien/CSS
refactor: Tai cau truc code
perf:     Cai thien hieu suat
test:     Them/sua test
chore:    Cong viec khac (build, config...)

🔄 QUY TRINH COMMIT TIEU CHUAN:
--------------------------------

1. Kiem tra thay doi:
   git status

2. Xem chi tiet thay doi:
   git diff

3. Them file:
   git add .

4. Commit:
   git commit -m "feat: Your message here"

5. Push:
   git push origin main


🌿 LAM VIEC VOI BRANCH:
------------------------

1. Tao branch moi:
   git branch <branch_name>

2. Chuyen sang branch:
   git checkout <branch_name>

3. Tao va chuyen sang branch:
   git checkout -b <branch_name>

4. Xem danh sach branch:
   git branch

5. Xoa branch:
   git branch -d <branch_name>

6. Merge branch:
   git checkout main
   git merge <branch_name>


🔙 HOAN TAC THAY DOI:
----------------------

1. Hoan tac file chua add:
   git checkout -- <file_name>

2. Hoan tac sau khi add:
   git reset HEAD <file_name>

3. Hoan tac commit cuoi:
   git reset --soft HEAD~1

4. Xem lich su commit:
   git log
   git log --oneline
