✅ Backend server PHAI dang chay

🌐 CACH 1: MO TRUC TIEP FILE HTML (Don gian nhat)
--------------------------------------------------
1. Mo File Explorer (Windows Explorer)
2. Di den thu muc: D:\Study Code\DataAnalyst\frontend
3. Double-click vao file:
   - index.html              → Trang chu
   - rankings.html           → Xep hang
   - compare.html            → So sanh
   - school-detail.html      → Chi tiet truong
   - advanced-analytics.html → Phan tich

→ Trang web se tu dong mo trong trinh duyet mac dinh


🚀 CACH 2: SU DUNG FILE BAT (Tu dong)
--------------------------------------
1. Double-click file: OPEN_WEBSITE.bat
2. Tat ca 5 trang se tu dong mo trong trinh duyet

→ Nhanh chong va tien loi!


💻 CACH 3: SU DUNG VS CODE LIVE SERVER (Khuyen nghi)
-----------------------------------------------------
1. Mo VS Code
2. Mo thu muc du an: File → Open Folder → Chon "DataAnalyst"
3. Cai dat extension "Live Server" (neu chua co):
   - Nhan Ctrl+Shift+X
   - Tim "Live Server"
   - Click Install

4. Click chuot phai vao frontend/index.html
5. Chon "Open with Live Server"

→ Trang web se mo tai: http://127.0.0.1:5500/frontend/index.html
→ Tu dong reload khi ban chinh sua code


🔗 CACH 4: MO BANG TRINH DUYET
-------------------------------
1. Mo trinh duyet (Chrome, Firefox, Edge)
2. Nhan Ctrl+O (hoac File → Open File)
3. Di den: D:\Study Code\DataAnalyst\frontend
4. Chon file index.html
5. Click Open

→ Trang web se hien thi


📱 CAC TRANG CO SAN:
--------------------
1. 🏠 TRANG CHU (index.html)
   - Dashboard tong quan
   - 6 KPI cards
   - 8 bieu do phan tich

2. 🏆 XEP HANG (rankings.html)
   - Top 20 theo Ty le choi

   - Bieu do phan bo nguyen vong
   - Truong tuong tu

5. 📊 PHAN TICH (advanced-analytics.html)
   - Thong ke mo ta
   - Ma tran tuong quan
   - Phan tich hoi quy
   - Box Plot
   - Bubble Chart
   - Outliers detection
